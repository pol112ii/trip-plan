# 🧳 여행 플래너 (Trip Planner)

폰에서 바로 쓰는 **1인용 여행 계획표 웹앱**.
설치·로그인·서버 없이 `index.html` 하나만 열면 끝. 내 데이터는 내 폰에만 저장됩니다.

<p>
지도 · 타임라인 · 예약 서류 · 도장/뱃지 · 오프라인 지원
</p>

---

## 바로 쓰는 법

### 1) 그냥 열기
`index.html` 을 브라우저로 열면 됩니다. (파일 하나만 있어도 동작하지만, 폴더째 두는 걸 권장)

### 2) 웹에 올리기 (추천)
폴더 전체를 아래 중 아무 데나 올리면 링크가 생깁니다.

| 방법 | 하는 법 |
|---|---|
| **tiiny.host** | 폴더를 zip 으로 압축 → 드래그 앤 드롭 → 링크 완성 (가장 빠름) |
| **GitHub Pages** | 이 저장소 → Settings → Pages → Branch 선택 → Save |
| **Netlify Drop** | app.netlify.com/drop 에 폴더 드래그 |

### 3) 홈 화면에 추가 (제일 편함)
링크를 폰 사파리/크롬으로 열고 **공유 → 홈 화면에 추가**.
앱처럼 전체화면으로 열리고, **비행기 모드에서도** 일정과 첨부 파일이 열립니다.

---

## 화면

| 탭 | 내용 |
|---|---|
| 🗺️ **오버뷰** | 그날 동선 지도(핀 번호 = 순서, 점선 = 이동 경로) · 요약 · 오늘 쓸 서류 · **그 도시 맛집 리스트** |
| 📋 **일정** | 시간순 타임라인. 길찾기 / 지도보기 / 캘린더 / 편집 / 삭제 / 완료 체크 |
| 📎 **서류** | 항공권 · 기차표 · 입장권 · 숙소 바우처 · 보험. 탭하면 바로 열림 |
| ⚙️ **설정** | 여행 정보, 날짜·도시·일수 편집, 맛집, 뱃지, 백업/복원, 테마 |

**하단 바** — `◀ 이전` / `📍 지금` / `다음 ▶`
`지금` 을 누르면 오늘 날짜로 이동해서 **현재 시각에 해당하는 일정**으로 스크롤됩니다.

## 주요 기능

**처음 열면 — 빈 여행으로 시작**
샘플 데이터가 미리 채워져 있지 않습니다. 첫 실행 때 뜨는 창에서
여행 이름 · 시작일 · 종료일 · 도시만 정하면 그 기간만큼 날짜가 자동으로 만들어집니다.
구조가 궁금하면 `⚙️ 설정 → 샘플 여행 둘러보기` 로 포르투갈 8일 예시를 불러올 수 있어요.

**날짜 · 도시 (며칠짜리든 자유롭게)**
`⚙️ 설정 → 날짜 · 도시 · 일수 편집` 에서
- **시작일/종료일**을 바꾸고 `기간 적용` → 3일이든 20일이든 원하는 길이로 (최대 60일)
- 늘리면 빈 날이 붙고, 줄이면 뒤쪽이 사라집니다 (일정이 든 날은 먼저 확인)
- 날짜별로 **도시를 다르게** 지정하거나, `전체 적용` 으로 한 번에
- 중간 날 삭제 시 남은 날짜가 자동으로 다시 매겨집니다

**맛집 리스트 (도시별)**
미리 저장해둔 맛집이 **그 도시로 지정된 날**의 오버뷰에 자동으로 뜹니다.
리스본 3일 + 포르투 3일이면, 리스본 날엔 리스본 맛집만 보이는 식이에요.
- 가게마다 지도 / 길찾기 / 링크 / **＋ 일정에** (그날 일정으로 바로 넣기)
- 아이콘을 누르면 **가봤어요 ✅** 체크

**지도**
- 하루 동선이 순서대로 핀 + 점선으로 그려집니다.
- 핀을 누르면 **구글맵 길찾기 / 위치보기** 버튼이 뜹니다.
- 저장해둔 **그 도시 맛집**이 분홍 테두리 핀으로 함께 표시됩니다 (`🍽️ 맛집` 버튼으로 켜고 끄기).
  오늘 동선 옆에 뭐가 있는지 한눈에 보라고 넣은 것 — 지도 바의 `구글맵` 버튼을 누르면
  그날 전체 동선이 경유지로 연결돼 구글맵 앱에서 열립니다.
- 일정 카드의 `🧭 길찾기` 는 이동수단에 맞춰 자동으로 모드를 고릅니다.
  (`도보/🚶` → 걷기, `트램·버스·지하철·기차` → 대중교통, 나머지 → 자동차)

**예약 서류**
- 링크를 넣거나, **PDF·이미지 파일을 직접 첨부**할 수 있습니다.
- 첨부한 파일은 브라우저 안(IndexedDB)에 저장돼 **인터넷 없이도** 열립니다.
- 로밍 안 되는 공항 카운터에서 티켓 꺼낼 때 이거 하나면 됩니다.

**게임 요소**
- 일정을 완료하면 체크 + 폭죽 🎉, 상단 **XP 바**와 레벨(여행 새싹 → 포르투갈 마스터)이 오릅니다.
- 하루를 다 끝내면 날짜 칩에 ✅ **도장**이 찍힙니다.
- 조건을 만족하면 **뱃지** 8종이 열립니다. (트램 탑승, 에그타르트, 전망대 정복, 미식 5회 …)

**그 외**
- 일정 하나 또는 전체를 `.ics` 로 내보내 **폰 캘린더에 넣기**
- 좌우 **스와이프**로 날짜 이동 (PC는 ←/→ 키)
- 오늘 일정을 카톡 등으로 **공유/복사**
- 라이트 / 다크 / 시스템 테마
- 여행 시작까지 **D-day 카운트다운**

## 내 여행으로 바꾸기

**방법 A — 앱 안에서 (쉬움)**
1. `⚙️ 설정 → 여행 제목 · 동행 수정`
2. `⚙️ 설정 → 날짜 / 도시 편집` 에서 날짜를 내 일정으로
3. `📋 일정 → ＋ 일정 추가` 로 하나씩 채우기
4. `📎 서류 → ＋ 서류 추가` 로 항공권·바우처 첨부

**방법 B — 파일로 (한 번에)**
`data.js` 를 직접 고칩니다. 형식은 이렇습니다.

```js
{
  time: "09:15",                 // 필수
  title: "렐루 서점",             // 필수
  type: "명소",                  // 명소 식당 이동 숙소 쇼핑 휴식 기타
  move: "🚶 도보 5분",            // 이동수단 (선택)
  place: "Livraria Lello",       // 장소 이름 (선택)
  lat: 41.1470, lng: -8.6148,    // 좌표 — 있어야 지도/길찾기가 뜸
  note: "예약번호 ABC123",        // 메모 (선택)
  warn: "시간지정 · 늦으면 무효"    // 주황색 경고 (선택)
}
```

> **위치 넣는 법 4가지** (좌표를 손으로 칠 일은 없습니다)
> 1. **이름으로 검색** — 일정/맛집 편집 화면의 `위치` 칸에 가게 이름을 치고 `검색`.
>    결과를 고르면 좌표가 자동으로 들어갑니다. (OpenStreetMap · 무료 · 키 불필요)
>    그날의 도시가 자동으로 검색어에 붙어서 동명 이곳이 덜 섞입니다.
> 2. **좌표 붙여넣기** — 구글 지도에서 장소를 길게 눌러 나오는 `34.6687, 135.5013` 를 복사해서 붙여넣기
> 3. **구글맵 주소 붙여넣기** — `.../maps/@34.6687,135.5013,17z` 같은 주소를 통째로 붙여넣어도 인식합니다
> 4. **현재 위치** — 지금 서 있는 곳을 그대로 찍기

## 저장과 백업

| 무엇 | 어디에 |
|---|---|
| 일정 · 서류 목록 | 브라우저 `localStorage` |
| 첨부 파일 (PDF/이미지) | 브라우저 `IndexedDB` |

전부 **이 폰 안에만** 있습니다. 서버로 아무것도 안 보냅니다.
다만 **브라우저 데이터를 지우면 같이 지워지니**, 여행 전에
`⚙️ 설정 → 내보내기(JSON 백업)` 를 한 번 눌러 파일로 받아두세요.
새 폰에서는 `가져오기` 로 복원합니다. (첨부 파일은 백업에 포함되지 않으니 다시 첨부해야 합니다)

`⚙️ 설정 → 샘플 데이터로 초기화` 를 누르면 `data.js` 의 기본 여행으로 되돌아갑니다.

## 파일 구성

```
index.html      화면 뼈대
styles.css      디자인 (라이트/다크 테마 토큰)
app.js          로직 — 렌더, 지도, 편집, 저장, 캘린더
data.js         기본 여행 데이터 ← 여기만 바꿔도 됨
sw.js           오프라인 캐시 (서비스 워커)
manifest.json   홈 화면 추가용
icon.svg        아이콘
```

지도는 **Leaflet + OpenStreetMap/CARTO** 를 씁니다 (무료, API 키 없음).
지도 타일만 인터넷이 필요하고, 나머지는 전부 오프라인에서 동작합니다.
